# `internal/pkg`

`internal/pkg` 目录用于存放仅供本项目内部使用的通用工具包或基础库。这些包不会被外部项目直接引用，Go 的包机制会限制只能被本项目 import，适合项目专用、可复用但不对外暴露的代码模块。


与 [`pkg`](../../pkg/) 目录不同：
- `internal/pkg`：仅本项目内部可用，外部无法 import，适合项目专用的工具包。
- [`pkg`](../../pkg/)：可被外部项目复用，设计为通用库，允许其他项目 import。

**建议**：如果你的包只服务于当前项目且不希望被外部依赖，放在 `internal/pkg`；如果希望对外复用，放在根目录下的 [`pkg`](../../pkg/)。
