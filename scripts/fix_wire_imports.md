# fix_wire_imports.py 使用说明

## 功能简介

自动调整 `wire_gen.go` 文件，使其符合 `rule.md` 中的规范：

1. **添加版权信息**：在文件开头添加三行版权声明
2. **调整 import 规范**：
   - 所有项目内包必须强制取别名
   - 别名前缀为 `app`，如 `appconf`、`applog`、`appbiz`
   - import 按字母顺序排序

## 为什么需要这个脚本

- `wire_gen.go` 是由 Wire 工具自动生成的代码
- Wire 工具生成的文件不包含版权信息
- Wire 工具生成的 import 可能不符合项目的 import 规范
- 每次运行 `make generate` 后，这些内容可能被重置
- 手动调整很繁琐，因此需要自动化脚本

## 使用方法

```bash
# 方式 1: 直接运行（推荐）
python3 scripts/fix_wire_imports.py

# 方式 2: 仅显示修改而不写入文件（演示模式）
python3 scripts/fix_wire_imports.py --dry-run

# 方式 3: 处理指定目录
python3 scripts/fix_wire_imports.py /path/to/project

# 方式 4: 显示帮助信息
python3 scripts/fix_wire_imports.py --help
```

## 集成到工作流程

脚本已集成到 `Makefile` 的 `generate` 目标中，会在 Wire 生成代码后自动执行：

```bash
# 修改 wire.go 配置后，运行：
make generate

# 该命令会自动：
# 1. 运行 go mod tidy
# 2. 执行 go generate ./...
# 3. 调用 fix_wire_imports.py 调整生成的文件
```

## 转换示例

### 添加版权信息

**转换前**：
```go
// Code generated by Wire. DO NOT EDIT.

//go:generate go run -mod=mod github.com/google/wire/cmd/wire
```

**转换后**：
```go
// Copyright 2025 fsyyft-go
//
// Licensed under the MIT License. See LICENSE file in the project root for full license information.

// Code generated by Wire. DO NOT EDIT.

//go:generate go run -mod=mod github.com/google/wire/cmd/wire
```

### 调整 import

**转换前**：
```go
import (
	"github.com/fsyyft-go/kratos-layout/internal/biz"
	"github.com/fsyyft-go/kratos-layout/internal/pkg/conf"
	"github.com/fsyyft-go/kratos-layout/internal/pkg/log"
)

func wireWeb(conf2 *conf.Config) {
	logger, _ := log.NewLogger(conf2)
	usecase := biz.NewGreeterUsecase(...)
}
```

**转换后**：
```go
import (
	appbiz "github.com/fsyyft-go/kratos-layout/internal/biz"
	appconf "github.com/fsyyft-go/kratos-layout/internal/pkg/conf"
	applog "github.com/fsyyft-go/kratos-layout/internal/pkg/log"
)

func wireWeb(conf2 *appconf.Config) {
	logger, _ := applog.NewLogger(conf2)
	usecase := appbiz.NewGreeterUsecase(...)
}
```

## 工作原理

1. **查找**：递归查找项目中所有 `wire_gen.go` 文件
2. **版权信息**：检测并添加三行版权声明（如果缺失）
3. **检测 import**：分析 import 部分，识别项目内包
4. **转换别名**：将直接导入转换为带 `app` 前缀的别名导入
5. **排序**：按字母顺序重新排列 import
6. **更新引用**：更新代码中对包的引用（如 `conf.` → `appconf.`）
7. **写入文件**：保存修改后的内容

## 依赖要求

- Python 3.6+
- 仅使用标准库，无需额外安装依赖

## 常见问题

**Q: 脚本会修改哪些文件？**  
A: 仅修改项目中的 `wire_gen.go` 文件。

**Q: 如何确认脚本正常工作？**  
A: 使用 `--dry-run` 参数预览修改，或查看运行后的统计信息。

**Q: 脚本会破坏代码吗？**  
A: 不会。脚本仅调整 import 格式和添加版权信息，不改变代码逻辑。如有疑虑，可先提交代码再运行脚本。

**Q: Python 环境检查失败怎么办？**  
A: 确保系统已安装 Python 3，并且 `python3` 命令可用。macOS 和大多数 Linux 发行版默认已安装。
